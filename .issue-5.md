Request for Gitignore File Addition

## What

Add a `.gitignore` file to the repository.

## Why

To ensure that unnecessary files and directories are not included in git version control, reducing the repository size and improving performance.

## How

Create a new `.gitignore` file at the root of the repository and include patterns for files and directories that should be ignored.

## Files Affected

Unknown

## Constraints

None

## LLM tier

sonnet

## Value

Medium Value

## Success looks like

- The `.gitignore` file is added to the repository.
- The specified patterns are correctly implemented.
- Unnecessary files and directories are no longer tracked by git.

## Failure looks like

- The `.gitignore` file is not added to the repository.
- Specified patterns are missing or incorrect.
- Unnecessary files and directories continue to be tracked by git.
